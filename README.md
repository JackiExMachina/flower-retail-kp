# PLUTON.CORE — Flower Retail / Digital Launch

Коммерческое предложение по цифровому запуску для цветочного бизнеса с офлайн-репутацией (сайт, карты Яндекс Бизнес / 2ГИС, каталог, аналитика и сопровождение).

## Стек и архитектура
- **Формат:** Чистый автономный HTML5 + CSS3 (Zero-Dependency).
- **Типографика:** Inter (Google Fonts) + системные шрифты.
- **Адаптивность:** Полный Mobile-First адаптив под смартфоны, планшеты и десктоп.
- **Хостинг:** GitHub Pages (Fastly CDN, прямой доступ без VPN и троттлинга ТСПУ).
- **SEO & Приватность:** Мета-тег `robots: noindex, nofollow, noarchive` для защиты от индексации поисковиками.
